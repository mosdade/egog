# Настройка Cloud Functions без плана Blaze

## Проблема

Firebase Secrets требуют план **Blaze (pay-as-you-go)**. На бесплатном плане Spark это недоступно.

## Решения

### Вариант 1: Обновить план до Blaze (рекомендуется) 🔒

**Преимущества:**
- ✅ Безопасное хранение секретов
- ✅ Бесплатный лимит: 2 миллиона вызовов в месяц
- ✅ Платите только за использование сверх лимита

**Шаги:**
1. Откройте: https://console.firebase.google.com/project/egog-771fc/usage/details
2. Нажмите **"Upgrade to Blaze plan"**
3. Добавьте способ оплаты (не будет списаний до превышения лимита)
4. После обновления используйте Firebase Secrets (см. [SETUP_SECRET_KEY.md](SETUP_SECRET_KEY.md))

### Вариант 2: Использовать переменные окружения (для тестирования)

**⚠️ Внимание:** Менее безопасно, но работает на бесплатном плане.

**Шаги:**

1. **Создайте файл `.env` в папке `egog/`:**

```bash
# egog/.env
SECRET_KEY_ENV=LAJDAUO+ayhgKmkge0Cq+4F5TXnyXzHrykvtJn6BeEk=
```

2. **Установите пакет для работы с .env:**

```bash
cd egog
npm install dotenv
cd ..
```

3. **Обновите `egog/index.js`** (добавьте в начало файла):

```javascript
require('dotenv').config();
```

4. **Разверните функции:**

```bash
firebase deploy --only functions:egog
```

**⚠️ ВАЖНО:** 
- Не коммитьте `.env` в Git!
- Добавьте `.env` в `.gitignore`
- Это менее безопасно, чем Firebase Secrets

### Вариант 3: Использовать старый API v1 (устаревший)

Можно использовать старый способ с `functions.config()`, но он устаревший и не рекомендуется.

## Рекомендация

**Для продакшена:** Обновите план до Blaze и используйте Firebase Secrets.

**Для тестирования:** Используйте переменные окружения (Вариант 2).
